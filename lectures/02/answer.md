  - `lr=0.0002`
  - `num_train_epochs=20`
  - `seed=42`
  - `warmup_steps=6`

- **自分で学習を実行したか（`executed_training_myself`）：** はい

- **学習前：** `format_rate` = 0.0952 / `content_rate` = 0.0000

- **学習後：** `format_rate` = 1.0000 / `content_rate` = 0.9048

- **学習後に残った失敗と、その型：**

  21問中2問で内容の誤りが残った。いずれも「根拠なしの質問に断定した」型だった。

  1. 「成績はいつ出ますか」
     - 学習後の回答：提出期限は9月30日23:59と回答した。
     - FAQには成績発表時期の情報がないにもかかわらず、課題の提出期限を当てはめて断定した。

  2. 「オフィスアワーは事前予約が必要ですか」
     - 学習後の回答：毎週火曜17:00〜18:00に受け付けると回答した。
     - FAQには事前予約の必要性について記載がないにもかかわらず、オフィスアワーの開催時間を回答して断定した。

  どちらも `needs_review: false` と回答したが、正しくは `needs_review: true` として確認を求める必要があった。

- **知識を問う質問（セクション6）の結果（学習前の分類 → 学習後の分類）と気づいたこと：**

  | 質問 | 学習前 | 学習後 |
  |---|---|---|
  | 最終課題の締切 | format_error | asserted |
  | 担当教員の名前 | format_error | needs_review |
  | 次回講義のテーマ | format_error | needs_review |

  学習前は4問ともJSONの形式エラーだったが、学習後は指定された形式で回答できるようになった。

  一方、FAQにない情報についても、既存のFAQにある提出期限を流用して断定する場合があった。

  このことから、出力形式を学習することと、回答に根拠があるかを適切に判断することは別の問題だと分かった。

- **学習で変わったこと・変わらなかったこと：**

  学習によって形式遵守率は約9.5%から100%に、内容正解率は0%から約90.5%に改善した。指定されたJSON形式や、FAQに基づいた回答パターンを学習できたと考えられる。

  一方、FAQに記載のない質問に対して、関連する別のFAQの情報を当てはめて断定する問題は残った。

  LoRAによるファインチューニングで出力形式を改善できても、未知の情報に対する適切な判断までは保証されないことが分かった。

## 宿題

- **取り組んだレベル：** 基礎

- **変えた設定やデータ：**

  `CONFIG` の `num_train_epochs` を20から10に変更して再学習した。

  `lora_r=16`、`lr=0.0002`、`seed=42` などの設定、および学習・評価データは変更していない。

  設定を変更する前にセッションを再起動し、同一条件で比較した。

- **結果（比較表や数字）：**

  | 評価項目 | 20エポック | 10エポック |
  |---|---:|---:|
  | format_rate | 1.0000 | 1.0000 |
  | content_rate | 0.9048 | 0.8571 |
  | 最終記録のTraining Loss | 0.013796 | 0.097869 |
  | 学習時間 | 246秒 | 111秒 |

  エポック数を20から10に減らしても、形式遵守率は100%のままだった。一方、内容正解率は約90.5%から約85.7%に低下し、正解数が21問中19問から18問に減少した。

  最終記録のTraining Lossは10エポックの方が高かったが、学習時間は246秒から111秒へ約55%短縮された。

  今回の実験では、10エポックでも出力形式を十分に学習できた一方、内容正解率には若干の差が生じた。ただし、1回ずつの実行結果であるため、この差がエポック数の変更のみによるものとは断定できない。

- **ファインチューニングが向く場面・向かない場面についての考察：**

  ファインチューニングは、指定したJSON形式や回答パターンなど、モデルの出力形式や振る舞いを一定の形式に合わせたい場合に向いていると考える。

  今回の実験では、10エポックと20エポックの両方で形式遵守率が100%となり、比較的少ない学習でも形式を習得できることが確認できた。

  一方、FAQにない質問に対しては、学習後も根拠のない回答を断定する例が見られた。このため、ファインチューニングだけで未知の情報や更新される情報に正確に対応することは難しいと考える。

  正しい情報の参照や根拠の確認が重要なシステムでは、RAGなどによる外部データの検索・参照を組み合わせる方法が適していると考えた。
